### Loja Virtual – Trabalho 2 (Java RMI)

A aplicação implementa uma loja virtual em Java, utilizando RMI para comunicação entre cliente e servidor, registro de pedidos, consulta de produtos e envio de notificações.

Execução: iniciar Servidor.java e depois Cliente.java.

A descrição completa da implementação, os requisitos atendidos, os testes e as instruções de execução estão disponíveis no relatório enviado.
